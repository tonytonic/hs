# Compteur Heures & Paie – PWA hors ligne

## 📌 Contexte du projet

À l’origine, ce projet est né d’un **besoin personnel**.

J’ai d’abord créé un **fichier bêta simple en HTML** afin d’enregistrer mon historique d’heures supplémentaires **mois par mois**, avec un seul objectif :  
👉 vérifier que les heures réellement effectuées correspondaient bien à celles figurant sur mon bulletin de salaire.

Après plusieurs mois d’utilisation, l’outil s’est révélé fiable et cohérent.

---

## 👥 Évolution du besoin

La semaine suivante, un collègue a trouvé l’outil intéressant et a souhaité l’utiliser à son tour.  
C’est à ce moment-là que deux contraintes sont apparues :

- J’utilisais l’outil comme une **web-app native sur iPhone** (HTML simple ajouté à l’écran d’accueil)
- Lui utilisait **Android**, avec un besoin différent :
  - un **compteur d’heures** plus souple
  - une logique moins centrée uniquement sur la paie mensuelle

La version bêta initiale ne correspondait donc plus réellement à son usage.

---

## 🚀 Nouvelle direction

À partir de ce constat, j’ai décidé de :

- développer un **véritable compteur d’heures**
- améliorer le module **mensuel de paie**
- unifier l’ensemble dans une **application simple pour l’utilisateur**
- éviter les multiples étapes d’installation ou de configuration complexes

👉 **GitHub Pages s’est imposé comme la solution idéale** :
- hébergement simple
- application accessible immédiatement
- compatible iPhone, Android et PC
- installation possible comme une application (PWA)
- fonctionnement hors ligne
- données stockées localement sur l’appareil

---

## ⏱️ Objectif

L’objectif était clair :  
**proposer une V1 fonctionnelle, stable et utilisable en conditions réelles en moins d’une semaine**, sans backend ni dépendance serveur.

---

## 🔒 Données & responsabilité

Les données sont stockées **localement sur l’appareil de l’utilisateur**.  
Des fonctions de sauvegarde/export sont intégrées et **fortement recommandées**.

Cet outil est destiné à un **usage personnel et indicatif**.  
En cas de litige, seuls les documents officiels de l’employeur font foi.

---

## 🛠️ Technologies

- HTML / CSS / JavaScript
- PWA (Progressive Web App)
- Stockage local (localStorage)
- Fonctionnement hors ligne
- Compatible iOS / Android / PC
